# 元气小丑主机工程 10200001

本源码以收到的20261020主机源码为基础，本次新增P15范围、出奖分项、查账分组和两种模式的右屏退币。完整变更和C1～C50对照见 `Docs/版本10200001_变更与查账对照.md`。

## 版本号查看

进入查账菜单，翻到 C48 页：中屏显示 `1020`，右屏显示 `0001`，合起来为固件版本号 `10200001`。

C菜单已调整为50页，C42仍为算法版本14，C48为固件版本，C49/C50为旧账原始流水。固件版本不受清账影响，常量位于 `Service/Inc/game.h` 的 `GAME_FIRMWARE_VERSION`，规则为MMDDNNNN，如10200002、10210002。安全包release维持独立递增，不能改成这个显示编号。

随包的20261019说明书作为历史参考；当前P15范围和C页定义以本次变更对照为准。

## 编译入口

使用 Keil MDK、ARM Compiler 5.06 update 5（build 528），安装 `Resources/KeilPack` 中的 GD32F4xx DFP 3.5.0 芯片包。

- 普通主机工程：`Projects/MDK-ARM/joker_gd32f407.uvprojx`；不带打码功能的普通工程为同目录 `joker_gd32f407_no_lock.uvprojx`。
- FUAH：`Projects/MDK-ARM/joker_gd32f407_iap.uvprojx`，编译 `Joker_V1_APP_A`、`Joker_V1_APP_B`。
- NO_FUAH：`Projects/MDK-ARM/joker_gd32f407_no_lock_iap.uvprojx`，编译 `Joker_V1_NO_LOCK_APP_A`、`Joker_V1_NO_LOCK_APP_B`。

编译后BIN导出命令已适配本机 `C:\Keil_v5\ARM\ARMCC\Bin\fromelf.exe`；其他电脑安装位置不同时，在Keil的Options for Target → User → After Build/Rebuild中调整该路径。本次修改需要从源码重新编译，旧的一键工具所附预编译固件不会自动变为新版。

主工程包含完整源码、上述Keil工程、链接脚本、RTE头文件、芯片包、说明和本次回归测试，并已生成六个Target的编译产物。本次未改写既有Release目录中的旧升级包，也未更新已经发出的预编译工具包。制作10200001升级卡必须使用当前源码新编译的A/B固件；现成旧IAP不代表这个版本。
