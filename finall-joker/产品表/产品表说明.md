# 产品表说明

`devices.csv` 一台机器一行，保存设备号、完整 96 位 UID 和随机 256 位设备密钥。

`product_models.csv` 固定记录产品型号与 Flash 分区。`universal_package_history.csv` 由 v2 制包工具追加每次通用发布的 release、授权数量、A/B SHA-256 和输出位置。`package_history.csv` 仅保留旧 v1 历史记录。

- UID 必须是从 `0x1FFF7A10` 开始、按地址递增读取的 12 字节。
- `device_key_hex` 由登记工具随机生成，不能人工使用固定值。
- 不要用 Excel 自动转换设备号或 UID；本文件按文本处理。
- 至少保存两份离线加密备份。丢失某台设备密钥后，无法再为它制作升级包。
- 当前尚未启用芯片读保护，调试器仍可能读出 Sector 11；这只是联调阶段状态。

登记示例：

```powershell
python ..\制包工具\register_device.py --id 143-001 --uid 00112233445566778899AABB
```

登记完成后会在 `身份文件\143-001` 生成需要首次烧录到 Sector 11 的 BIN 和 HEX。
## 授权状态

`devices.csv` 的 `status` 只允许两个值：`active` 和 `inactive`。请优先通过根目录`元气小丑生产升级工具.cmd`修改，不要手工改 UID 或 `device_key_hex`。

`active` 机器会进入下一个通用升级包；`inactive` 机器不会进入。状态修改对已经发出的旧 TF 卡无效。
